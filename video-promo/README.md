# Рекламный ролик «Создаём сайт для вашего бизнеса»

Вертикальный ролик для Telegram-канала: 1080×1920, 30 fps, 33.0 с, H.264 / yuv420p + AAC.
Собран целиком из исходников в этой папке, сторонние фонограммы и стоковые видео не используются.

Готовый файл: `out/promo-sites-1080x1920.mp4`

## Что внутри

| файл | что это |
|---|---|
| `STORYBOARD.md` | идея, варианты по каждой сцене и выбранное решение, тайминги, палитра |
| `src/index.html` | страница-носитель холста 1080×1920 |
| `src/anim.js` | вся графика и анимация: камера, перспектива, макеты интерфейсов, кинетическая типографика |
| `src/audio.js` | музыка и звуковой дизайн, синтез в `OfflineAudioContext` |
| `src/fonts/` | Manrope (кириллица), подмножества из пакета `@fontsource/manrope` |
| `audio/vo*.wav` | пять реплик дикторской озвучки |
| `render.mjs` | рендер кадров и музыки через Playwright, кадры идут прямо в ffmpeg |
| `probe.mjs` | снимок отдельных кадров в PNG для разбора композиции |
| `build-audio.sh` | сведение: речь + музыка с приседанием музыки под голос |
| `build.sh` | полная сборка от исходников до финального MP4 |

## Сборка

```bash
./build.sh              # всё целиком (рендер кадров ~25–30 минут)
./build.sh --mux-only   # пересобрать только звук и контейнер
node probe.mjs 3.4 12.0 27.5          # посмотреть отдельные кадры
node probe.mjs 27.5 --full            # в полном разрешении
```

Нужны `ffmpeg`, Node 22 с `playwright` и установленным Chromium.

## Технические решения

**Графика.** Canvas 2D с собственным управляемым таймлайном: `renderFrame(t)` зависит только
от `t`, поэтому любой кадр воспроизводится после перемотки, а рендер можно продолжить
с любого места. Перспектива — проекция `s = fov/(fov + z − camZ)`; развороты макетов
вокруг вертикальной оси собираются из 56 полос с собственным масштабом, то есть это
настоящая перспектива, а не аффинный наклон. Глубина резкости считается от `|z − focus|`,
motion blur — накоплением 2–4 подкадров со сдвигом 0.55 кадра.

**Кадрирование под 9:16.** Макеты сверстаны в альбомных пропорциях, поэтому их положение
задаётся явно через `frameTo(ширина_в_пикселях, логическая_ширина, высота_центра)`:
верхняя полоса отводится под заголовок, нижняя под подпись, макет живёт между ними.
Кегль заголовков автоматически ужимается под безопасные поля, чтобы строка не обрезалась.

**Звук.** Музыка синтезируется в `OfflineAudioContext`: пэд, саб-бас, арпеджио, ударные,
райзеры и вуши. Акценты (импакт, райзер, вуш) стоят ровно на границах сцен.
Речь — RHVoice, голос `aleksandr-hq`, темп 94 % от нормы без постобработочного ускорения.
При сведении музыка приседает под голос сайдчейн-компрессором.

**Важно про содержание.** Все показанные экраны — иллюстративные макеты, собранные
для этого ролика. Это не портфолио и не выполненные клиентские работы; названия,
цены и цифры условные.

## Ограничения проверки

Композиция, тайминги, тексты, технические параметры экспорта и уровни звука проверены
инструментально (покадровый разбор, `ffprobe`, `astats`, детект пауз). Субъективное
качество звучания синтезированной речи и музыки на слух не оценивалось — в этой среде
нет воспроизведения звука.
