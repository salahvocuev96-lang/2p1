# Рекламный ролик «Создаём сайт для вашего бизнеса»

Формат: 1080×1920, 30 fps, H.264 / yuv420p, AAC. Длительность 33.0 с (990 кадров).

## Палитра и язык

| роль | цвет |
|---|---|
| фон глубокий | `#05070E` → `#0A1020` |
| поверхность UI | `#111827` / `#161E33` |
| основной акцент | `#4F8CFF` |
| вторичный акцент | `#8B5CF6` |
| подсветка | `#22D3EE` |
| текст | `#FFFFFF` / `#8B9BB4` |

Типографика: **Manrope ExtraBold 800** — заголовки, **Manrope 600/400** — интерфейсы.
Глубина: три плана (BG z≈−900 сетка и ауроры, MID z≈0 интерфейсы, FG z≈+320 частицы и блики),
перспективная проекция `s = fov/(fov+z−camZ)`, DOF по |z−focusZ|, motion blur накоплением
подкадров (2 в покое, 4 на быстрых фазах).

## Варианты и выбор по сценам

### Сцена 1 — 0.0–4.2 «Вашему бизнесу нужен сайт?»
1. Текст собирается из разлетающихся фрагментов UI.
2. Пустое тёмное окно браузера, мигающий курсор, набор адреса, окно рассыпается в вопрос.
3. Пролёт камеры по сетчатому тоннелю к знаку вопроса.
4. Силуэт витрины магазина в темноте, по нему проходит луч.
5. Кинетический набор по словам с маск-вайпом, позади в перспективе прочерчивается каркас браузера.

**Выбрано: 5 + 2.** Кадр начинается с пустого каркаса окна, который прочерчивается сам (причина:
«сайта ещё нет»), в адресной строке набирается `вашбизнес.ру`, вопрос выходит по словам масочным
вайпом со вспышкой на каждом слове. Камера отъезжает и слегка кренится — задаёт глубину сразу.
Выход: вспышка + вайп-пан влево.

### Сцена 2 — 4.2–10.4 «Современные сайты для вашего бизнеса»
1. Три карточки сайтов влетают и складываются стопкой в 3D.
2. Окно браузера собирает само себя: хром → hero → навигация → сетка → кнопки.
3. Карусель сайтов, вращающаяся вокруг вертикальной оси.
4. Страница быстро проскроллена, камера облетает.
5. Тоннель из миниатюр, одна фиксируется в центре.

**Выбрано: 2 + 4.** Окно собирается поблочно с пружинной динамикой, позади — два расфокусированных
дубля (параллакс). Затем страница проскроллена до секции товаров, камера одновременно наезжает
и уводится вбок. Выход: наезд «сквозь экран».

### Сцена 3 — 10.4–18.4 (три разных бита, не один шаблон)
- **A 10.4–13.0 «Красивый дизайн»** — сетка карточек каталога каскадом, обложки-градиенты, цены;
  камера с наклоном, DOF по рядам.
- **B 13.0–15.7 «Удобство»** — меню кафе: строки с фото, названиями и ценами; курсор наводится,
  строка подсвечивается, счётчик корзины тикает. Показана интеракция, а не статика.
- **C 15.7–18.4 «Адаптация под телефон»** — десктопное окно сжимается в телефон, вёрстка
  перетекает из трёх колонок в одну; телефон доворачивается в 3D.

Текст меняется тремя кинетическими подменами на одной строке.

### Сцена 4 — 18.4–25.0 «От идеи до готового сайта»
1. Вайрфрейм превращается в готовый дизайн морфом.
2. Экраны пролетают мимо камеры в коридоре.
3. Сплит: слева вайрфрейм, справа результат.
4. Рельс с узлами идея → дизайн → сайт, камера едет вдоль.

**Выбрано: 1 + 4.** Сначала набрасывается вайрфрейм (пунктир, серые блоки), затем слева направо
проходит «полоса проявки», превращая его в цветной готовый сайт; камера едет вдоль рельса,
в глубине подменяются десктоп и телефон. Причинность «идея → результат» читается буквально.

### Сцена 5 — 25.0–33.0 финал
Экраны слетаются к центру и схлопываются в светящуюся линию, из неё раскрывается заголовок.
Три строки выходят лесенкой: «Создаём сайт для вашего бизнеса» → «Стоимость обсуждается
индивидуально» → пилюля CTA «Напишите мне в личные сообщения» с бумажным самолётиком.
Финальный кадр держится 2.9 с с медленным дрейфом и световым пробегом по тексту.

## Музыка и звук

Синтез в `OfflineAudioContext` (Web Audio), 128 BPM, 48 кГц стерео — оригинальный материал,
сторонние фонограммы не используются.

- 0.0–4.2 пэд + саб, редкие тики, райзер на 3.6
- 4.2–10.4 вход бита: кик, бас, арпеджио 1/16
- 10.4–18.4 плотная часть: клэп на 2 и 4, яркий арп, филлы на стыках битов
- 18.4–25.0 билд: открытие фильтра, райзер
- 25.0–30.1 пик: полный микс + аккордовый стэб
- 30.1–33.0 хвост: реверб, отпускание саба

SFX: вуш на переходах, тик на появлении слов, импакт на старте сцен, чайм на финале.
Голос поднят над музыкой сайдчейн-компрессором при сведении (музыка приседает ~9 дБ под речь).
