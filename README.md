# Чайхана «Ташкент»

Сайт ресторана узбекской и домашней кухни в Москве (улица Зорге, 2).

## Структура проекта

```
/
├── index.html      — главная страница сайта
├── css/
│   └── style.css   — стили (можно расширять и модифицировать)
├── js/
│   └── script.js   — логика сайта (поиск, корзина, меню)
├── logo.png        — логотип (используется в репозитории)
└── README.md       — этот файл
```

## Возможности

- **Интерактивное меню** с категориями и поиском
- **Корзина** для добавления блюд
- **Демо-версия оформления заказа**
- **Адаптивный дизайн** (мобильные устройства, планшеты, компьютеры)
- **Стиль на основе риштанской керамики** — кобальт, бирюза и шафран

## Быстрый старт

1. Открыть `index.html` в браузере
2. Или развернуть на хостинге (просто скопировать все файлы)

## Развитие проекта

### Добавить блюда в меню

Отредактируйте массив `MENU` в файле `js/script.js`:

```javascript
const MENU = [
  { 
    id: 'new-dish',           // уникальный ID
    name: 'Название блюда',   // как показывается на сайте
    category: 'hot',          // категория: hot, soups, other, salads
    price: 350,               // цена в рублях (или null, если неизвестна)
    description: '',          // короткое описание (опционально)
    photo: '',                // путь к фото (опционально)
    featured: false           // true — показать как крупная карточка на широком экране
  },
  // ... остальные блюда
];
```

### Изменить стили

Все стили находятся в `css/style.css`. Там же определены переменные цветов и шрифтов.

Основные цвета (в `:root`):
- `--cobalt` — кобальт
- `--saffron` — шафран
- `--teal` — бирюза
- `--ink` — основной текст

### Подключить реальный заказ

В `js/script.js` найдите функцию `checkoutForm.addEventListener('submit', ...)` — туда добавьте отправку данных на сервер.
