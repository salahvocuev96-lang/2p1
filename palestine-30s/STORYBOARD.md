# «Газа. Ночь» — 30 с, раскадровка

**Нить:** одна ночь в Газе. Тишина → удар → руины → голод → мать с ребёнком → небо в огне → люди, брошенные под стеной с флагом → призыв. Флаг виден с первого кадра (на стене слева) и возвращается финальным символом.

**Стиль (из `full_3.mp4`):** густые мазки маслом, фиолетово-индиговое ночное небо горизонтальными полосами, тёмно-синие силуэты фигур, огненные «молнии» с неба, тёплый огонь против холодной тьмы. Сюжет и кадры — свои, референс не копируется.

**Музыка:** звук из `IMG_6771.MOV` (вход на 3.75 с, провал 10.8–12.8 с, удары 13.42 / 14.12 / 15.05 / 16.74 / 17.07 / 18.18 / 20.11 / 21.83 / 23.41 / 24.54 / 26.26 / 28.47 с). Поверх — свой SFX: свист, взрывы, приглушённые удары за стеной, ветер с пеплом.
