# Rolex Submariner — смена стилей · раскадровка

Формат: 1920×1080, 60 fps, 52 с, музыка 120 BPM (такт = 2 с) + звуковой дизайн.
Единая нить: **одни и те же часы проходят путь от карандашного эскиза до готового предмета** —
каждый стиль «вырастает» из предыдущего (эскиз → шаблон для вырезания → контуры загораются →
заливка → слои расходятся → получают толщину → разбираются → собираются → коронка с циферблата
становится логотипом). Стрелки идут в реальном времени всё видео.

Постоянный экранный индикатор этапа (вверху слева) + кинетический заголовок каждого стиля (внизу слева).

|---|---|---|---|---|
| 1 Карандаш | 0–6 | циркуль-построение; **крупно за грифелем → отъезд**; слово SUBMARINER превращается в безель; чертёж-синька | вспомогательные круги и оси → корпус → безель → метки → стрелки → браслет → штриховка; камера от 12 часов отъезжает, лёгкий крен | шорох грифеля по ходу штриха, тик часов на долях |
| 2 Бумага | 6–12 | ножницы вырезают эскиз; оригами-разворот; **лист крафта накрывает эскиз, детали падают вырезками**; аппликация из обрывков | лист съезжает справа, на нём белый шаблон эскиза; детали падают stop-motion 12 к/с на восьмые доли, с тенями и отскоком; безель проворачивается с щелчками | шелест листа, хлопки бумаги на каждое приземление, трещотка безеля |

| 7 Разборка | 36–41 | **взрыв-схема по оси с подписями**; детали разлетаются по кругу; разрез корпуса | 12 деталей расходятся по вертикали, подписи привязаны к проекциям деталей, камера отъезжает и облетает | whoosh + звон деталей |
| 8 Сборка | 41–45 | **обратная сборка деталь за деталью на восьмые доли**; магнитный «щелчок» всего сразу | каждая деталь садится со щелчком, камера выходит во фронт и ныряет в коронку на циферблате | щелчки по сетке, разгон |
| 9 Логотип | 45–52 | **match cut: коронка с циферблата становится золотым логотипом**; буквы из стрелок; гравировка | коронка заливается золотом, буквы ROLEX поднимаются с трекингом, блик, подпись SUBMARINER, медленный наезд | удар + шиммер, ноты на буквы, финальный аккорд с хвостом |

Главный риск: единая 3D-проекция для всех стилей (плоские слои → 2,5D → толщина) — проверен пробными кадрами перед полным рендером.
