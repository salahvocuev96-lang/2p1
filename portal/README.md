# Education Portal · Налоговый колледж (демо MVP)

Интерактивный прототип: вход по ролям, дневник, журнал, средний балл, посещаемость, задания, сообщения, админ-панель.
Расписание 22 групп взято из `../all-groups.json` (реальное), студенты и родители вымышленные.

## Запуск

```bash
cd portal
npm install
npm run dev      # http://localhost:3000
npm run build    # статическая сборка в portal/out (можно залить на любой хостинг)
```

## Архитектура

```
src/
  app/                 маршруты Next.js: / (вход) и (cabinet)/<раздел>
  components/          дизайн-система (ui.tsx), AppShell (сайдбар + нижнее меню), иконки
  features/            экраны по ролям: student, teacher, admin, shared
  lib/
    types.ts           доменная модель
    seed.ts            построение демо-базы из расписания
    store.ts           хранилище + actions (LocalStorage), единственное место записи
    access.ts          права доступа (кто что может менять)
    stats.ts           средний балл (месяц/семестр/год), посещаемость
    nav.ts             меню каждой роли
```

Правила:
- Оценки (`grades`) и посещаемость (`attendance`) это две разные таблицы.
- Любая запись идёт через `store.ts` и проверяется в `access.ts`: студент не может менять оценки, преподаватель работает только со своей связкой «предмет + группа».
- Нагрузка преподавателя считается из расписания автоматически.
